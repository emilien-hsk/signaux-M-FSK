PC RECEPTEUR (micro)
====================

1) Installation (une seule fois) :
   pip install numpy scipy matplotlib sounddevice

2) Reglages : desactiver la reduction de bruit / "ameliorations audio" du micro
   (Parametres Windows > Son > micro > Proprietes).

3) Lancer l'ecoute :
   python test_reel.py ecouter --M 4 --distance 1 --bruit calme

   --M        : 2, 4, 8, 16 ou 32 (le MEME que sur l'emetteur)
   --distance : en metres (0.5, 1, 2, 3)
   --bruit    : calme ou musique

   - Attendre "Pret : en attente d'un message" (1 s de mesure du bruit ambiant,
     ne pas faire de bruit pendant ce temps).
   - L'emetteur joue un message. Le recepteur le detecte, l'ecoute jusqu'au
     SIGNAL DE FIN (son qui descend), reconnait le texte (T1 a T5), ecrit une
     ligne dans resultats_reels.csv, puis S'ARRETE.
   - Le son capte est sauvegarde dans le dossier enregistrements/.

   Pour une serie de tests sans relancer a chaque message, ajouter --continu :
   python test_reel.py ecouter --M 4 --distance 1 --bruit calme --continu
   (il reste a l'ecoute apres chaque message ; Ctrl+C pour arreter)

   Si les messages ne sont pas detectes (loin, son faible) : --sensibilite 1.8
   S'il se declenche tout seul (bruit) :                     --sensibilite 4

4) A la fin de la seance, pour faire le graphique du poster :
   python analyse_reels.py
   -> cree fig_tests_reels.png

MODE BOUCLE (un seul PC + un baffle)
====================================
Le baffle est la sortie son du PC, le micro du PC ecoute :
   python test_reel.py boucle --M 4 --texte T1 --distance 1 --bruit calme
(--distance = distance entre le baffle et le micro du PC)

Reanalyser un enregistrement sauvegarde (le texte est reconnu tout seul) :
   python test_reel.py analyser --M 4 --distance 1 --bruit calme --fichier enregistrements\NOM.wav
